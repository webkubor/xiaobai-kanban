# 关于我们

> **我们只做一件事：让普通人不花钱、少踩坑地用上 AI，并且在 AI 时代跑完属于自己的那一圈闭环。**

---

## 为什么会有这个站

大多数 AI 教程有一个共同问题：**它们是写给已经会写代码的人看的。**

一上来就是 `npm install`、`git clone`、环境变量、API Key、Docker。
会的人觉得理所当然，不会的人第一行就卡住了——不是不聪明，是**没人告诉他这一步在干嘛、失败了算什么**。

另一边，网上又有大量「AI 让你月入十万」的内容。
它们卖的是焦虑，不是能力。

这个站是第三条路：

| 常见教程 | 常见课程 | 我们 |
|---|---|---|
| 假设你已经会了 | 卖焦虑，先收钱 | 假设你什么都不会，**从「Agent 是什么」开始讲** |
| 只讲工具，不讲为什么 | 讲概念，不给可执行步骤 | 每个概念配一个**你能亲手做完的小任务** |
| 默认你要买订阅 | 默认你要报班 | 默认你**一分钱不想花**，先告诉你免费额度怎么用 |

## 我们相信的四件事

### 1. 门槛是「不知道」，不是「学不会」

小白卡住的地方，九成不是逻辑难，而是**没人把默认前提说出来**：

- 「终端」在哪、打开长什么样
- 报错里哪一句提示了真正的原因
- 装完了怎么知道它真的生效了

所以我们尽量把每一步需要什么、该怎么做、如何确认结果写清楚，让初次接触命令行的人也能跟着尝试。

### 2. 先跑通，再理解

先让你做出一个能打开的网页，再去解释什么是 Git、什么是提交。
顺序反了，人就在第二篇放弃了。

### 3. 免费不是降级，是选择

国内一线模型（DeepSeek、GLM、Kimi、MiniMax……）现在写代码的能力已经够用了，
配上 [magpie 本地网关](/docs/magpie)，**可以不花一分钱开始**。

我们不会因为「免费」就给你阉割版教程。
真正该花钱的地方（比如要稳定跑生产、要团队协作），我们会明确告诉你**什么时候该花、花在哪**。

### 4. 闭环比工具重要

会用十个工具，不如完整跑通一次：

```
想法 → 讲清需求 → Agent 写 → 你验收 → 改到能用 → 发布上线 → 有人用
```

这条链上任何一环断了，前面的努力都归零。
所以这个站的重点不是「教你多少个工具」，而是**陪你把这一圈跑完一次**。

## 这些内容为什么免费

因为**教程本身不该是门槛**。

这里的教程和仓库里的开源工具可以免费使用；想自己走完全程，直接按[目录](/catalog)学就行，不需要先加客服。

如果你希望有人结合你的电脑环境帮忙排查，或陪你把一个具体项目从想法做到上线，可以扫码说明需求。**基础答疑免费；需要持续陪跑或定制服务时，我们会先沟通范围和费用，由你自己决定是否继续。**

| 你想做的事 | 方式 |
|---|---|
| 自己按教程学、用开源工具 | 免费自助 |
| 遇到具体卡点，想让人看一眼 | 扫码咨询，基础答疑免费 |
| 需要持续陪跑或团队定制 | 扫码说清目标，先沟通范围与费用 |

我们不会把「加客服」当成阅读教程的前提，也不会在页面上虚构价格或承诺尚未确认的服务范围。
