# 🌊 AI 流式接收包

做 AI 对话界面最难的不是后端，是把流式响应正确地拆帧、拼成消息、还能中途取消。这个包处理 SSE 分帧、OpenAI / Anthropic 协议适配和不可变消息 patch，前端直接用。
