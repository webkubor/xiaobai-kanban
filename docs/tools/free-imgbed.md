## 它解决什么问题

一个 GitHub 仓库就是一台图床。图片 push 进仓库，jsDelivr 自动做全球 CDN 分发，CI 负责把「图片 ≤2MB、视频 ≤10MB」的红线守住。你只需要 fork 一份、改个名字就能用，不用买服务器、不用备案、不用续费。
