# 🔐 本地密钥库

> 把 API Key、Token、密码从明文文件挪进 AES-256-GCM 加密的本机密钥库，让 Agent 只能用别名去取凭据，永远碰不到明文。解决「密钥写在 .env 里被…

## 它解决什么问题

把 API Key、Token、密码从明文文件挪进 AES-256-GCM 加密的本机密钥库，让 Agent 只能用别名去取凭据，永远碰不到明文。解决「密钥写在 .env 里被 AI 读进上下文」这个经典事故。
