# 👁️ 前端自愈遥测

> AI 写完前端，页面报错了你却只能对着空白页猜。这个 Vite 插件把运行时日志、错误时的 DOM 快照和截图攒成结构化数据，交给 Agent 直接读——让 AI 能自己看到它…

**仓库**：[github.com/webkubor/vite-plugin-agent-eyes](https://github.com/webkubor/vite-plugin-agent-eyes) · 开源项目

---

## 它解决什么问题

AI 写完前端，页面报错了你却只能对着空白页猜。这个 Vite 插件把运行时日志、错误时的 DOM 快照和截图攒成结构化数据，交给 Agent 直接读——让 AI 能自己看到它写错了什么。
