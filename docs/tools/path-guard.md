# 🔍 PATH 诊断

> 命令行报「command not found」但你明明装过了？多半是 PATH 里有两个版本，真正执行的不是你以为的那个。这个 CLI 会告诉你实际跑的是哪个二进制、哪个旧版本…

**仓库**：[github.com/webkubor/path-guard](https://github.com/webkubor/path-guard) · 开源项目

## 它解决什么问题

命令行报「command not found」但你明明装过了？多半是 PATH 里有两个版本，真正执行的不是你以为的那个。这个 CLI 会告诉你实际跑的是哪个二进制、哪个旧版本在挡路、哪条软链已经悬空。
